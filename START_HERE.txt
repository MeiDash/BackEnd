🚀 COMEÇAR EM 5 MINUTOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  CRIAR AMBIENTE VIRTUAL
    $ python -m venv venv
    $ venv\Scripts\activate

2️⃣  INSTALAR DEPENDÊNCIAS
    $ pip install -r requirements.txt

3️⃣  CONFIGURAR VARIÁVEIS
    $ cp .env.example .env
    (Edite o arquivo .env com suas credenciais)

4️⃣  INICIALIZAR BANCO DE DADOS
    Opção A (Script):
    $ python init_db.py

    Opção B (Docker):
    $ docker-compose up -d

5️⃣  EXECUTAR APLICAÇÃO
    $ python run.py

💻 EXEMPLOS DE USO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURL - Login:
  $ curl -X POST "http://localhost:8000/api/auth/login" \
    -H "Content-Type: application/json" \
    -d '{"email":"admin@example.com","password":"admin123"}'

Python - Criar Usuário:
  import requests
  response = requests.post('http://localhost:8000/api/users',
    json={'email':'novo@example.com','username':'novo','password':'senha123'})

JavaScript - Listar Usuários:
  fetch('http://localhost:8000/api/users', {
    headers: {'Authorization': 'Bearer ' + token}
  }).then(r => r.json())

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Erro: "ModuleNotFoundError: No module named 'fastapi'"
  → Execute: pip install -r requirements.txt

Erro: "Connection refused" PostgreSQL
  → Verifique se PostgreSQL está rodando
  → Ou use: docker-compose up -d

Erro: Port 8000 já em uso
  → python run.py --port 8001

CORS error no Frontend
  → Adicione URL do frontend em ALLOWED_ORIGINS no .env
